#     与 `L_IDLE => L_DONE`（`cg_lsu_fsm.t_idle_done`：非对齐 ⇒ 不发请求直接报 fault）——
#     这两条不能用 riscv-tests 的 env 触发（其 `trap_vector` 只把 ecall 类引向 tohost，
#     其余异常一律 TESTNUM=1337 ⇒ HALT_FAIL）。
