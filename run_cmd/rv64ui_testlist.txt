# 口径（务必读）：
#   · 一行一条用例名，**必须**逐字匹配 `sim/image/rv64ui/MANIFEST.json` 里 `tests[].name`
#     （解析不到即 fail-closed 报错，不静默跳过——"跑了 49 条"不得冒称"跑全 50 条"）；
#   · `#` 起头为注释；空行忽略；**不支持**任何 per-case 开关（比对列/放宽开关一律不走 testlist，
#     红线 R6：`--final-only` 之类只允许白名单 + 逐次登记）；
#   · 清单本身受 md5 记账（runner 写进 `config.json`）：换 testlist 即换配置 ⇒ **不得**拿它当"同配置两轮"。
#
# 当前集合 = MANIFEST 在册全量 50 条（riscv-tests rv64ui-p-*，`sw/tests/build_rv64ui.py` 产）。

#
# **为什么是 50 而不是 52**（2026-09-26 心跳第 10 轮 M3-(d)「补缺指令」批实测面）：
#   · 36 条（心跳第 8 轮）＋ 新纳入 14 条（blt/bge/bltu/bgeu/jalr/lb/lbu/lh/lhu/lwu/ld/sb/sh/sd；

#     ⇒ 50 条在册（＝本清单 ＝ `MANIFEST.tests` ＝ `m2-rv64ui` 的判定子集）；
#   · 2 条不在册，**逐条原因落 `sim/image/rv64ui/GAP.json` 的 `pending_subset`**（不静默跳过）：
#       缺机制 1 条（fence_i：自修改代码——测试体 `sh` 进**代码窗**再 `fence.i` 后 `jalr` 跳入；
#       本 TB 取指桩 `fmem` 是 `$readmemh` 只读镜像、写落盘只覆盖数据窗 ⇒ 代码窗 store 无承载；
