# script/tmp — 临时脚本区（用完即删）

## 规则（依据 `AGENTS.md` §2 与 `.gitignore`）

- 本目录用于**一次性/临时脚本**：问题定位探针、一次性格式转换、批量文本处理等。
- **问题解决、不再使用时必须及时删除**；不允许把长期有用的脚本留在这里——有价值的脚本应移入
  `script/`（工具）、`iss/tests/`（回归）或 `iss/tests/probes/`（评审证据）。
- 本目录**被 `.gitignore` 排除**（`script/tmp/*`），只有本文件被白名单保留（`!script/tmp/README.md`）——
  这是有意设计：临时件不入版本库，但目录本身必须能被 git/GitHub 传递。

## 与本目录相关的历史教训（勿重犯）

| 教训 | 出处 |
|---|---|
| R7 评审者把 34 个探针与输出写在这里，而本目录不入库 ⇒ **评审证据差点随清理丢失**，违反“结论可回溯” | `doc/00` ISS-022 |
| 证据已被迁出并升格：29 个 → `iss/tests/probes/`、5 个 → `doc/spec/01-评审探针/` | 同上 |
| 新建目录若**不留占位文件**，git/GitHub 不收空目录 ⇒ 换机后目录消失、下游工具与队列项找不到落点 | `doc/00` ISS-035 / ISS-036 |

> 结论：**临时的东西可以放这里，但“证据”不行**——证据要么进 `iss/tests/probes/`，要么进 `doc/spec/*-评审探针/`。
