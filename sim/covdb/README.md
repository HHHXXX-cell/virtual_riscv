# sim/covdb — 签核证据受保护区（不得清理）

## 定位

本目录存放**批级合并后的覆盖率数据库与编译指纹**，是 `doc/07` 覆盖率报告与 Review G3 签核的
**原始证据**。依据 `AGENTS.md` §2 与 `doc/spec/01` §7：逐用例 ucdb 不可相加，必须批级 `vcover merge`
后再判定，合并集限**同一编译版本**。

## 规则

| 规则 | 说明 |
|---|---|
| **不得清理** | 任何 `clean` 目标、脚本、AI 例行操作都**不得删除本目录内容**；`.gitignore` 有意保留本文件（`!sim/covdb/README.md`）使目录能随仓库传递 |
| **必须可追溯到源** | 每个 `<batch>.ucdb` 旁必须有指纹文件（RTL 版本 + filelist hash + 编译选项 + 工具版本 + 合并来源 ucdb 清单） |
| **不算正式证据前不得引用** | 未记录指纹或跨编译版本合并的数据，只能作参考，**不得写进 `doc/07`/`doc/09`** |
| 大文件不入库 | ucdb 体积大，按 `.gitignore` 排除；归档责任在项目侧（拷贝到受控存储），**但目录与说明必须入库** |
