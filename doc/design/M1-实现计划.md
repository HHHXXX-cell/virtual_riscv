| 项 | 内容 |

| 里程碑 | **M1**（`state/flow.json`）＝ `vlog` **0 error** ＋ 定向下 **RTL-vs-ISS 逐指令 trace 0 mismatch** |

| 程序规模 | **30 条退休**（26 条主序含 1 条异常退休 ＋ 4 条 handler）；源＝`iss/tests/test_smoke.py:build_words()` |

| 比对 | `python iss/tools/trace_compare.py sim/golden/iss_smoke.csv <rtl_side.csv>`；列 `pc,binary,gpr,csr`（`DEFAULT_COLS`） |

### 1.2 两条 exit 判据（已在 `script/flow.py` 的 `CHECKS` 注册）

| 判据名 | 可执行形式 | 现状（2026-09-25 本批） |
|---|---|---|
| `rtl-compile` | `python script/flow.py check-one rtl-compile`：**编译 `filelist/rtl.f`**，判 `Errors: 0` ＋ `-- Compiling` 计数 == 清单条目数 ＋ vlog 退出码 0 | **已真实化**（本批把 BLOCKED 桩换成实判据）；实跑 = `PASS：vlog 编译 2 个单元 ｜ Errors: 0` |
| `rtl-vs-iss` | 同 1.1 的比对命令，判**长度相等且 mismatch=0** | **保持 BLOCKED 桩**（永不返回 True）：RTL 侧 trace 产出未实现 ＋ TB 侧写出器/停机判据/watchdog 未就位 ＋ 仿真器不可用 ⇒ **无比对物** |

> `rtl-vs-iss` 的消息**刻意不含** `ENV-BLOCKED` 字样：剩余面里既有环境项（ISS-104），也有实打实的实现工作
> （RTL/TB）——属"未完成"而非"环境挡住"，混档会让 `flow.py check` 以退出码 3 收场、掩盖真进度。

### 1.3 判定纪律（本计划期间不得放宽）

1. **只判 trace 与编译**：拍数／IPC／预测准确率**不在 M1 判据内**（清单 §3「性能口径」行）；`cycle`/`mispred`/`seq`
   三成员不参与比对（`spec/01` §3.21 尾注，`iss/README.md` §3）。
2. **列集不得改**：比对列固定 `pc,binary,gpr,csr`；`--final-only`／`--with-asm` 只允许按 testlist 白名单启用并登记
   `doc/verify/05`（红线 R6）。
3. **产物落盘才算数**：每步证据 = `sim/run_<step_id>/run.log` 的命令与输出行；"跑完没 error"不作判据（红线 R8）。
4. **流断裂先归因**：两侧长度不等时先按环境/激励归因（批中止判据 `AB1`/`AB6`），不逐条硬比
   （`iss/tools/trace_compare.py` 行为）。
5. **未实现不得包装成"部分通过"**：本批 `rt_v`/`commit_valid` 恒 0，宁可让比对报"长度不等"（可归因），
   也不产一条假 trace 去骗过比对。

### 4.1 trace 写出器：`rt_t` → CSV（列序＝`TRACE_CSV_FIELDS`）

| `rt_t` 成员 | CSV 列 | 规则 | 参与比对 |
|---|---|---|---|
| `pc` | `pc` | 8 位十六进制、无 `0x` | ✅ |
| `instr` | `binary` | 8 位十六进制原始字 | ✅ |
| `rd_idx`,`rd_data`,`rd_wb_en` | `gpr` | `<abi名>:0x%016x`；**`rd_idx==0` 或 `rd_wb_en==0` ⇒ 空串** | ✅ |
| `csr_addr`,`csr_new`,`csr_wr_en` | `csr` | `0x<addr 3位>:0x%016x`，**取写后新值**；`csr_wr_en==0` ⇒ 空串 | ✅ |
| `priv` | `mode` | `PRV_U`/`PRV_S`/`PRV_M`（首版恒 `PRV_M`） | ✅（`--cols` 可关） |
| `mispred`/`cycle`/`seq`/`mem_*` | （debug 列/无列） | **不参与比对** | ❌ |
| `instr_str`/`operand` | 反汇编文本 | 默认关闭（工具自定义文本会造假 mismatch） | ❌默认 |

- 口径出处：`iss/README.md` §3（映射唯一权威表）＋ `doc/process/00` **ISS-013**（`csr` 列取**写后新值**＝`rt_t.csr_new`，
  只给旧值无法直接判 CSR 行为）＋ `iss/tools/trace_compare.py` 的 `DEFAULT_COLS`/`NON_COMPARED`。
- **归一化**由 `iss/vriss/trace.py:normalize_row()` 承担（数值等价即等价）；TB 侧按上表**字面**写出即可，
  不必复刻 ISS 的 ABI 名表——但字面值必须能被归一化器等价（`gpr`/`csr` 的取值以 `0x` 十六进制为口径）。

### 4.3 内存桩（一份镜像喂两边）
