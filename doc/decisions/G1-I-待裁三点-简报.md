# G1-I 待裁三点 · 决策简报（一页）

> **用途**：供 R0 **一句话作答**（答法：`①A ②A ③A`）。三点互不耦合，可分别作答；三点全取推荐项 ⇒ **G1-I 范围不变、今天可签**。
> **出处**：三点均出自 `doc/decisions/G1-I-最小冻结清单.md` §4（`GI-6`／`GI-10`）与 §6.2 ①（`GS-3`／`GS-4`／`GS-7`）——长清单不在此重抄，本页只给"可作答"的最小面。
> **共性**：三条都不是"要不要改判据"，而是"**材料缺项**如何处理"（豁免／先补／回避），三者均不影响接口面。

## ① `rt_t` 是否以"补 `spec/01` §3.21 附录（RVFI 三清单）"为 G1-I 前置

- **【问题】** `spec/01` §3.21 自述「附录未填前本节不得作 G1 冻结依据」，而 `rt_t`（543 bit）是 M1 trace 比对的唯一真值接口——是"先补附录再冻"，还是"由 R0 明示豁免该自述句、直接冻"？
- **【选项】** **A（推荐）** 明示豁免该自述句，`rt_t` 照冻，附录转下游义务（G1-F 前补）／ **B** 硬前置：先派 spec 落文批填三清单，再签 G1-I／ **C** 把 `rt_t` 移出 G1-I，首版自定 trace 接口。
- **【后果】** A 今天可签，残余＝唯一材料缺项被**显式豁免**（回退＝一次性补附录，不动接口）／ B 签发推迟一轮落文＋RR（依据最完备）／ C 同 B，且首版失去 trace 判据、引入"自造接口"越界风险。
- **【推荐】A**——附录补的是"字段 ↔ RVFI/CSV 列"的**映射说明**（材料完备性），接口成员级位域表已具备且 `types-*` 机判在册，映射落文不改接口定义本身。
- **【G1-I 范围变化】** 范围**不变**（`rt_t` 仍冻）；`GS-7` 的"前置"降为下游义务，签署记录写明"R0 明示豁免该自述句"。

## ② `mtval` 非对齐取值口径（spec 侧无成文）是否接受"以规范＋ISS 为准、spec 后补"

- **【问题】** 非对齐 store（cause 6）的 `mtval` ＝ 出错 VA，目前只存在于规范与 ISS 实现里，`spec/10` §4.1 未成文——是否接受"G1-I 期以规范＋ISS 实现为准，`spec/10` 后补一行"？
- **【选项】** **A（推荐）** 接受该临时口径，补文转下游义务／ **B** 硬前置：`spec/10` §4.1 成文并过 RR 后才签（`GI-6` 先绿）／ **C** 回避：首版删掉非对齐 store 用例。
- **【后果】** A 可签，首版断言的依据＝规范＋ISS＋机判三角，规格侧留一处**过渡态临时裁定**（须显式标注）／ B 推迟一轮 spec 落文（一行）／ C 要重做镜像与 golden（异常用例是 smoke 核心），并放弃首版唯一异常面。
- **【推荐】A**——与项目既定"规范为一级依据、spec 侧后补"口径一致，一行落文不改接口；B 只换形式完备却让主线白等一轮。
- **【G1-I 范围变化】** 范围**不变**；`GI-6` 由"未覆盖＋材料缺"改为"未覆盖（下游义务 `GD-3`）"，签署记录注明临时裁定。

## ③ `ibuf_wr_t`／`lq_alloc_t`／`sq_alloc_t` 的"折入既有型／恒等旁路"自决是否认可

- **【问题】** 首版**不定义** `ibuf_wr_t`（D 级直读 `spec/01` §3.3 的 `fetch_raw_t`、展开级恒等旁路），LQ/SQ 分配结果**折入** `rob_alloc_t`／`iq_wr_t`、不设 `lq_alloc_t`／`sq_alloc_t`——是否认可？
- **【选项】** **A（推荐）** 认可（三型留在 §3 延后到 G1-F，首版不定义、不例化）／ **B** 认同一半（`ibuf_wr_t` 先定义，保 M04/M05 模块边界）／ **C** 三型都先定义再冻。
- **【后果】** A 首版最省、G1-I 保持最小；代价＝G1-F 升版时重排控制组内部信号（**接口面不变、不触发重签**）／ B 多一张字段表落文与 23→24 型冻结面／ C 冻结面接近全量，与一期"能力与方法证明"定位冲突。
- **【推荐】A**——三型都不在首版实例化面上：镜像全 4 B 对齐且无 C ⇒ 展开级恒等旁路可用；`lq_id`/`sq_id` 成员已在既有型在册；"先定义"属"以后可能要用"，违反清单 R-c 不扩大。
- **【G1-I 范围变化】** 范围**不变**（三型本就在 §3 不含集）；签署记录注明"折入／旁路为 G1-I 期口径，按 §5 的 v5／v6 升版补型"。
