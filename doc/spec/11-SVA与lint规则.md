## 2. 监视器信号名绑定表（对 `spec/01` §7 / §8.2 待同步清单的核对口径）

- **绑定来源**：`spec/01` §7 断言引用的信号名与采样点，须在**本篇成稿时逐条绑定核对**（`spec/01` §8.2 待同步清单既有义务）。
- **核对判据**：每条断言列「引用名 → 定义处（篇＋节）」；**非 DUT 端口名**（如 `commit_fl_ret_vec`/`rollback_fl_ret_vec` 类监视器内部信号）必须显式标注为"TB 从采样口构造"（`spec/01` §7 同款声明）。
- **覆盖度接口**：断言的**失败路径**须与 `doc/verify/02` 的 VP 组对应（VP-X05 变异自检；A17/A18 的假绿/假红面见 §5.3 口径）。

## 3. lint 规则与可综合子集

| # | 规则 | 口径 | 引 |
|---|---|---|---|
| L-01 | 可综合子集 | 只用 IEEE 1800-2009/2012 已有特性（`AGENTS.md` §1） | `AGENTS.md` §1 |
| L-02 | 禁 1800-2023 新特性 | `soft` 约束／`tagged union`／`$assertcontrol`／`default disable iff` 禁用（工具覆盖度） | 知识库《SV标准1800-2023差异知识库》 |
| L-03 | 断言风格 | SVA 写法遵循本篇 §1/§2；时序窗口一律显式（禁裸 `##[1:$]`） | `spec/01` §7 |
| L-04 | 命名 | 信号/端口名与 `spec/01` §3 逐字一致（跨篇引用不许改名） | `spec/01` §2/§3 |
| L-05 | 位宽书写 | 显式位宽（禁隐式截断）；跨篇引用只引不赋值 | `spec/00` §4 |
| L-06 | 复位语义 | 断言复位范围与 `spec/00` §4.7 复位口径一致（异步复位同步释放） | `spec/00` §4.7 |
| L-07 | 禁止项（RTL 侧） | 禁 latches/门控时钟（`GATE_CLOCK_EN=0`）/组合环；循环须有界 | `spec/00` §4.7；`spec/04` §3.3 |

## 4. 工具覆盖度约束（ModelSim SE 2020.4）

- 断言与覆盖率写法须在 ModelSim SE-64 2020.4 上可编译可跑（`AGENTS.md` §3.1 命令口径；证据行＝ADR-5）；
- DPI-C 不用（本机无宿主编译器）⇒ 断言与检查一律 SV 原生（`AGENTS.md` §3.4 坑位 1）；
- 覆盖率合并仅限同一编译版本 ⇒ covdb 记编译指纹（`AGENTS.md` §3.4 坑位 3）。
