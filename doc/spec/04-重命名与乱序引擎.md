### 2.3 可写 SVA 形式与缺项

（1）`INV-1` 守恒（逐拍）：

```
// 观测来源：free-list 表按"已分配未提交集 + 空闲集"推导（监视器内部信号）
a_inv1: assert property (@(posedge clk) disable iff (!rst_ni)
  (alloc_cnt + free_cnt) == PRF_INT_ENTRIES);   // 64（spec/00 §4.3）
```

缺：`alloc_cnt`/`free_cnt` 的观测实现未在 `spec/01` 端口/struct 定义（须 TB 层次采样或本篇次片定义状态观测包，T-04-1）。

（2）`INV-2` 整组停顿（禁部分分配）：

```
// 组边界由 rob_alloc_t.grp_last（spec/01 §3.6）构造；两计数为监视器内部量
a_inv2: assert property (@(posedge clk) disable iff (!rst_ni)
  dispatch_grant_grp |-> (alloc_lane_cnt_grp == 0 || alloc_lane_cnt_grp == dest_lane_cnt_grp));
```

缺：per-lane 分配使能与组计数的监视器展开（`doc/verify/02` 覆盖面对接 T-04-6）。

**（L5 补）`INV-2`·未覆盖面·缺项单列**（不改上述已写形式；闭合归 `spec/11`）：①**停顿侧**——`free_cnt < n ⇒ !dispatch_grant_grp`（低水位判据；现行式只覆盖「授予 ⇒ 全或无」一侧）；②组目的数 `n` 与 `alloc_lane_cnt_grp` 的按拍观测展开（含跨拍组边界）。

（3）`INV-3` 仅提交拍释放被覆写旧条目：

```
a_inv3: assert property (@(posedge clk) disable iff (!rst_ni)
  prf_fl_release_fire |-> commit_stage_grant);
// 且释放对象 ⊆ 本拍提交 lane 的 commit_t.rd_old_paddr 集合（spec/01 §3.17）
```

缺：free-list 写口采样（监视器内部）；回滚路径的归还不入本条（归 `INV-5`）。

**（L5 补）`INV-3`·未覆盖面·缺项单列**（不改上述已写形式；闭合归 `spec/11`）：①**释放对象隶属**——「释放对象 ⊆ 本拍提交 lane 的 `commit_t.rd_old_paddr` 集合」现仅为注释句、无断言形式；② `prf_fl_release_fire`／`commit_stage_grant` 与逐 lane `rd_old_paddr` 的按拍采样。

（4）`INV-4` 提交不阻塞（安全面）：

```
// rob_head_commit_ready 定义式不含 free-list 项（构造上排除，即本不变式本体）
//   rob_head_commit_ready ≜ rob_head.finish ∧ L1D_done ∧ CSR_rd_done
a_inv4: assert property (@(posedge clk) disable iff (!rst_ni)
  rob_head_commit_ready |-> commit_fire);
```

有界活性（有限拍内必提交）不写无界 SVA；落统计项 `perf_freelist_stall_cycles`（`spec/01` §7 A2 配套）与 `doc/verify/02` 覆盖项。
缺：`rob_head_commit_ready` 聚合信号由监视器组装（未在 `spec/01` 定义）。

（5）`INV-5` 冲刷归还两路：

```
// 路 1：checkpoint 恢复（三元快照，1 拍；spec/01 §5.3）
a_inv5a: assert property (@(posedge clk) disable iff (!rst_ni)
  flush_apply && flush_needs_ckpt |=> (fl_head == FL_ck[flush_ckpt_id]) && (sp == SP_ck[flush_ckpt_id]));
// 路 2：逐条回滚（弹出即归还，spec/01 §5.3）
a_inv5b: assert property (@(posedge clk) disable iff (!rst_ni)
  (rollback_pop && rollback_pop_new_alloc) |-> fl_ret_fire(rollback_pop_new_paddr));
```

双归还互斥由 `spec/01` §7 A13 兜底（位图交集判据）；缺：`FL_ck`/`SP_ck` 快照向量与栈读口的采样（§5.3 已定义三元快照，可采）。
"两路"含义 = checkpoint 批量回池 + 逐条回滚显式归还，互补且不重叠（`spec/01` §5.3 N-01/N2 定案）。

## 3. `K` 的推导（硬交付 B；本篇定值）

### 3.1 定义与语义

`K` = **csrq 写口在途界**：某写口于第 `t` 拍点火且未命中时，仅当存在一次覆盖该写 `rob_id` 的**截断生效**
于区间 `[t-K, t]`（含同拍，截断优先）时，该丢弃计 `drop_cnt_squash`（合法）；否则置 `sticky_drop_illegal`（只清于复位）。
依据 = `spec/01` §3.19 规则 4 定案②（ISS-041/ADR-2）、§7 A17（现行窗口由 `$past` 1..2 表达）与 A18。
本计数不占 PERF 事件表（`PERF_EVT_NUM=8` 已定死，`spec/01` §3.19）。

### 3.2 同时钟域前提

两个写口（S 侧 `src_val`、E 侧 `old_val`）与 csrq 同在 `CLK_DOMAINS=1` 域内；A17 的 `$past` 采样即核拍——
故 `K` 是纯核拍量；二期若引入跨域接口（如总线异步 FIFO）不改变本界。

### 3.3 逐级算式

`K ≥ max(L_S, L_E)`；`L_x` = 写口 x 的**"条目可截断点 → 写点火"最坏在途拍数**，含队满反压/停顿项。
分解：`L_x = d_x + q_x + s_x`（d = 写路径固有寄存级数；q = 队满反压项；s = 停顿项）。

**「条目可截断点」定义（L5 补；锚＝§3.1 的「截断生效于区间 `[t-K, t]`」与两写口寄存器级数）**：写口 x 的「条目可截断点」＝该写所依条目（按 `rob_id` 命中的目标条目）的**截断生效拍**（冲刷把 csrq 截断到冲刷点之前、该条目被作废的那拍）；`L_x`＝自该拍起、一个**已进入写路径**的写**仍可能点火**（写端寄存输出）的最坏拍数——点火一旦进入写路径即不再被上游事件推迟（q/s 项为 0 的依据见下），故其上界＝写路径深度 `d_x`。**逐式复算**：S＝`W` 读出拍产生的写在次拍落槽＝1＝`d_S`；E＝「写 ≤ `E` 拍」＋写端 1 级寄存＝2＝`d_E`；⇒ `K = max(1, 2) = 2`，与下方定值一致。（定义如与后续评审读法冲突，以 `L_S=1`／`L_E=2`／`K=2` 既有锚定为准、定义随评审修正）

- **写口 S**（`src_val` 写；值于 `W`（发射选择）拍读出，`spec/01` §3.5 N-05；读点 片①-A9 定案；**清单④ 对账（S-08 批，2026-09-24）**：本写口 ≡ `spec/01` §3.19 的「`W` 级写 `src_val`（后读拍）」写口——BLK-3 更正后该篇现行名为 **`W`**，「S」为 A9 落文前旧名，**同一个物理写口**；`d_S`／`L_S` **变量名保留**（历史命名、篇内一致），数值与推导不变）：
  `d_S = 1`（写端 1 级寄存：读出拍产生的写在次拍落槽）；`q_S = 0`；`s_S = 0`；得 `L_S = 1`。
- **写口 E**（`old_val` 写；E 级投机读出，`spec/01` §3.10；门控在 P9 选择拍、E 级不重判）：
  `d_E = 2`（写 ≤ E 拍（§3.19 ①）＋写端 1 级寄存）；`q_E = 0`；`s_E = 0`；得 `L_E = 2`。

**得 `K ≥ max(1, 2) = 2`；本篇定值：`K = 2`**（与现行暂定值一致——机制不动，仅值来源改判）。

- q 项为 0 的依据：csrq 的队满反压只作用于 `R` 级入队（`spec/01` §3.19 深度依据句"溢满时 `R` 级反压"）；
  两个写口为按 `rob_id` 命中的比较写、无握手段，队满不推迟点火。
- s 项为 0 的依据：点火只随该级处理拍产生；被冲刷截断的 μop 不再推进、不再产生点火（`spec/01` §5.2 各级冲刷动作），
  故上游停顿不构成"截断后推迟点火"的通道。
- **两条机制约束（实现禁则，破坏即触发 §3.5 重算）**：P-w1 写端口不得引入独立可停顿缓冲/握手；
  P-w2 写路径寄存级数不得超过 S = 1 / E = 2。

### 3.4 紧致性说明

`K` 每多 1 拍 ⇒ A17 的合法窗口扩大 1 拍 ⇒ 掩盖"条目已提交出队型"非法丢弃的面（**假绿面**）扩大；
`K` 每少 1 拍 ⇒ 合法迟写被判 `sticky_drop_illegal`（**假红**）。故 `K` 取紧上界 `max(L_S, L_E)`，
不得放整、不得加经验裕量。

### 3.5 回退点

- 实现给写口加寄存级或可停顿缓冲（破坏 P-w1/P-w2）⇒ 按 §3.3 重算 `K` 并同步 §3.6 三处引用点。
- 执行体长度与 `K` 无关（`L_x` 只取决于写路径寄存级数；更长的 EU 只增大 §3.19 ① 构造性上界的余量）——
  该句为**前提**；若 `spec/06` 定稿引入"可取消/可重放"的写口时序，本算式随之复核。
- `K` 与 `K_stall`（队头就绪至其发射的等待拍硬上界，`spec/01` §3.10 BLK-1 消歧）**是两个量**：
  本定值不涉 `K_stall`，后者列 §7 T-04-4。

### 3.6 回写义务（定值后）

1. `spec/01` §3.19 规则 4："`K` 暂定 2" → "`K=2`（定值来源 `spec/04` §3）"；`K*≠2` 的三个分支**不触发**（`K*=2`），
   即此前"A17 未报错"类结论**无需重跑**——此判定以本片算式成立（P-w1/P-w2 未被实现破坏）为前提。
2. `spec/01` §7 A17：窗口保持 `$past` 1..2（**数值不动**），来源改引本篇 §3；A18 不涉窗口、不动。
3. `spec/00` §10：ISS-041 行回填"`K=2` 已定值（`spec/04` §3）"。
以上回写由**后续片**执行（本片不改 `spec/00`/`spec/01`）。

**（S-08 批复核，2026-09-24）三项回写现状**：①`spec/01` §3.19 规则 4 已改为「`K`＝2（已由 `spec/04` 定值……R-048）」——在文 ✓；②`spec/01` §7 A17 窗口已写 `1..K`（`K`＝2、来源引本篇 §3）——在文 ✓；③`spec/00` §10 ISS-041 行已载「`spec/04` 定值已给出：`K`＝2」——在文 ✓。⇒ §3.6 三笔义务**闭合**（`K*=2`，三分支不触发）。

## 4. S1 / SUS-01 读点口径收口

### 4.1 结论一：读点定义（级/拍/条件）

- **数据面操作数读点**：`OPND_READ_POLICY=后读`（`spec/00` §4.4）。**结构判据**：`iq_wr_t`（`spec/01` §3.8，237 bit）
  逐成员无操作数值域 ⇒ "队列不存值"（§3.11 注）为硬约束 ⇒ 值不可在 `S` 级读出后跨队列存活 ⇒
  读点**必不早于发射选择（P9 选中之后）**；载体 = `disp_x_t.rs1_val`/`rs2_val`（§3.11）。
  条件：该拍被选中且未被同拍冲刷；CSR 类 μop 另加队头门控（§3.10 I-01 定案，A16 兜底）。
- **CSR 源值读点（提交面专用）**：`rmap_uop_t.rs1_val` 在 **`W`（发射选择）拍（P9）** 读出（§3.5，N-05 标注；读点 片①-A9 定案），
  经 csrq 的 S 写口（清单④ 对账：≡ `spec/01` §3.19 的 `W` 读出口——读出拍＝`W`、次拍落槽，见 §3.3 对账注）按 `rob_id` 命中存入 `csrq_entry_t.src_val`（`spec/01` §3.19）。条件：该 lane 本拍有效且未被同拍冲刷。
- **言词冲突留痕**：§3.11 的"分发级已读出的操作数"若将"分发级"读作 `S` 级，则与 237 bit 载荷无值域自相矛盾；
  本篇按结构证据取"读点不早于发射"，**措辞对账列为缺项 T-04-5a（**R0 2026-09-23 裁定：撤销**——与 `spec/01` §3.11「原"分发级已读出"措辞作废」重复登记，不得再作缺项计入）**。**（D-14 落文遗留收口片）读点口径由片①-A9 闭合**：片①-A9 定案＝读值唯一在 `W`（发射选择）拍读 PRF（`spec/01` §1.1/§3.5/§3.11/§3.19），与本篇“不早于发射选择”的取法及 6×2 发射级读法（§4.2 ②）一致。

### 4.2 结论二：与 `PRF_RD_PORTS` 逐项闭合（**已全闭合：16 = 4 + 12**——ADR-S08，2026-09-24）

- **4（提交读，N9）——闭合**：提交拍读 `PRF[rd_paddr]`，每拍 `COMMIT_WIDTH=4` 口（`spec/01` §3.21 N9 ①；`spec/00` §4.3 行）。
- **12（行注"`DECODE_WIDTH×3` 分发读操作数"）——不能唯一闭合**：两种读法数值相等：
  ① 4 lane × 3 读点（分发级读；但"3"的第三项在原 `rs3` 删除后（`spec/01` §3.4 Q6）已无成员可指）；
  ② `ISSUE_WIDTH=6` × 2 源（发射级读，与结论一相合；读法选择**由片①-A9 闭合**——片①-A9 定案读点＝`W`（发射选择）拍）。⇒ 缺对账（T-04-5b 仅余 `spec/00` §4.4 行注落文对账；**不许本篇改 `spec/00`**）。
- **2（恢复读）——无承载方 ⇒ 删除（ADR-S08，2026-09-24）**：`spec/01` 全篇无消费方（回滚路径明写"不恢复 PRF 数据"，§5.2 `R` 行；checkpoint 只恢复映射三元；重试重读复用 6×2 口）⇒ **`PRF_RD_PORTS` 18→16**（`spec/00` §4.3 已落，版本批行 `v0.1 续6`）；T-04-5c 关闭。

### 4.3 结论三：与 N-05（`rs1_val` 打点于 S）的值载体闭合

## 5. PRF 容量面复核与联动公式

### 5.1 复核（ADR-S2 值）

`HIST_DEPTH=33`、`ROLLBACK_MAX=33`（`spec/00` §4.3，ADR-S2，2026-09-23）；本篇复核确认，联动公式见 5.2。
栈满反压 = `S` 级（`spec/01` §5.3，与 BP2 同口径）；栈条目 27 bit（`spec/01` §5.3，N3/N-01 融合形态）。

### 5.2 联动公式与复算

- 联动公式：`HIST_DEPTH = ROLLBACK_MAX = PRF_INT_ENTRIES - 31`（31 = 常驻钉住的架构态 `x1`~`x31`；ISS-003 决策列）。
- 快照字段位宽：`FL_ck` = 与 free-list 分配指针同宽；`SP_ck` = `log2(HIST_DEPTH)` 上取整；两者均 = `PADDR_W`（64 项时为 6 bit）。
- 复算（现行 64）：栈存储 = `HIST_DEPTH × 27 = 33 × 27 = 891` bit；
  快照存储 = `CHECKPOINT_COPIES × (RAT_ENTRIES × PADDR_W + FL_ck + SP_ck) = 4 × (32 × 6 + 6 + 6) = 4 × 204 = 816` bit。
- 两行的 `spec/00` §4.8 回填由后续片执行（§8-4）。

### 5.3 备选：PRF 128 扩容切换清单（未采纳；ADR-S2 维持 64）

触发判据写死（ISS-003 决策列）：反压停顿占比大于 15%；或裸机均值 IPC 小于 1.62 且归因 PRF；或 M5 实测 IPC 小于 1.5
且 PRF 主瓶颈；或 G1 前 `INV-1`~`INV-5` 未成可机判件。若采纳"直取 128 = `ROB_ENTRIES`"，联动更新：

- `PADDR_W` 6 → 7：**全链改动面**（`spec/00` §4.3 行注）。
- `HIST_DEPTH` = `ROLLBACK_MAX` = `128 - 31 = 97`；`SP_ck`/`FL_ck` = 7 bit。
- 复算：栈存储 = `97 × 27 = 2619` bit；快照存储 = `4 × (32 × 7 + 7 + 7) = 4 × 238 = 952` bit。
- 机制不动项：`INV-1`~`INV-5` 语句不变（参数化）；`CHECKPOINT_COPIES=4`、`ROLLBACK_RATE=8` 不变。

本清单为**备选**；采纳须过规格升版 + Requirement Review，不在本篇内自决。
