## 这轮评审对机制自身的结论

1. **R7 有效性已被证实**：评审者在只拿到文档 + 参数表、看不到作者任何推理的条件下，一次性揪出 21 项阻塞问题，其中包含**作者自己写下的虚假自检陈述（Q21）**。作者的自评表无法发现这类问题，因为它本身就是造假的位置。
2. **A/B/C 三类的价值排序**：C 类（Q16/Q17/Q18/Q19/Q20）**比 A 类算术错误更值钱**——算术错会在生成 struct 时立刻炸，而"回滚与 ROB 释放互相拆台""trace 看不见 PA 错误""NMI 进得去出不来"这三类是能一路活到硅前后期、并以"假绿"形式骗过签核的缺陷。下一轮评审任务模板要**强制先做 C 类**。
3. **残余风险未消除**：R7 没能力判断"这些设计决定本身对不对"（例如 Q17 的映射历史栈方案是否真的够深）。那属于 `spec/04` 的推导 + 人评审范围，不能因为"子代理评审过了"就从 Review G1 的评审清单里划掉。
4. **本次未跑 ISS 评审**：同一轮派出的第二评审者（针对 `iss/vriss/machine.py` 的 RV64 语义）被中断，需补做。
