| 项 | 口径 | 引 |
|---|---|---|

| VIPT 选型 | 32KB/8way 恰为 4KB×8 上限 ⇒ **TLB 并行且无别名**（同页内索引一致） | `spec/00` §5 D7 |

## 2. MSHR 与未命中处理

- **职责**：未命中请求按地址**合并**（同一行的多个请求共用一次填充）；填充完成经 `mshr_wake_t` 唤醒等待者（`spec/01` §3.16）。
- **条目数/合并粒度**：**登记**（`spec/06` T-06-2 同源）——本篇不另定；回退点＝若需要更多 outstanding ⇒ 调 `AXI_OUTSTANDING`（`spec/00` §4.7，2R+2W）并走升版。
- **写回**：dirty 行淘汰走写回路径（L2 non-inclusive，`spec/00` §5 D10）；写回与填充的仲裁归深化片（登记 T-09-2）。
- **与 PTW 的关系**：walk 请求经 L1D（`spec/08` §2；仲裁＝`spec/08` **§2.1**，T-08-3 已闭，R-183）。

## 3. 取指粒度与窗口（权威口径）

| 项 | 口径 | 引 |
|---|---|---|
| 每拍取指窗口 | **32B**（`FETCH_BYTES`）＝16 个 16bit 候选槽／8 个 32bit 槽 | `spec/00` §4.1（Q11）；`spec/01` §3.3 |
| 行内偏移 | `ifetch_offset`（6 bit）＝32B 窗口在 64B 行内的偏移（**必须显式携带**） | `spec/01` §3.13 |
| walk 规则 | 16/32 bit 判定只在 P5（低 2 bit ≠`11`→16bit；＝`11`→32bit；起始可落任意槽） | `spec/01` §3.16；`spec/02` §2.2 |
| 跨窗 | 槽 15 起的 32 位（或跨窗字节）经 **`xw_carry`** 与次窗槽 0 拼接（62 bit 载体） | `spec/01` §3.16 ②；`spec/03` §2.4；`spec/05` §3 |
| 块布局约束 | 块起始 2 字节对齐；loop 终止＝末条字节取全；跨度上界 66B | `spec/03` §2.3/§2.4（B-1~B-4） |
| IBUF | 16 项；约束 `> IF_STAGES×DECODE_WIDTH` | `spec/00` §4.2 |

## 4. `slot16_vld` 回退点对照（ISS-045 条件）

- **现状**：`slot16_vld` 位**已删**（`spec/01` 窗口结构 338→322 位宽的既有裁定，ISS-045）；取指窗口的「槽有效」不再以独立位数组承载——由**槽位置＋边界信息**推导（归一口径＝`spec/01` §3.16 `icache_rsp_t` 现文）。
- **回退点（对照表）**：若后续（`spec/11` 断言化或 RTL 实现）证明「逐槽有效位」不可省略（例如部分槽无效仍需显式标记）⇒ **恢复 `slot16_vld` 但须走接口升版**，连带：`spec/01` §3.16 `icache_rsp_t` 位宽（322→338 量级）、`spec/00` §4.8 级间行与合计、`width_check` 复算（本条＝ISS-045 要求的回退点对照；触发条件回引 §3.16 三条件判定标准）。
- **本片立场**：**维持已删**；触发条件与量级如上，未触发前不作预留（避免"假预留"）。
