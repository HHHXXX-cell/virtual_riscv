## 2. TLB 与 PTW

- **TLB**：L1I 侧 `L1I TLB16`（`spec/00` §4.6）；L1D 侧条目数以 `spec/00` §4.6 为准（**条目位域与替换态归 `spec/09`**——登记 T-08-2）。
- **ASID**：`ASID_BITS_IMPL`（`spec/00` §4.6 行；【权】§4.1.11 锚点闭环状态见 `spec/00` §10）。
- **PTW**：单 walker（一期）；walk 请求的载体＝**`ptw_mem_req_t`＝`mem_req_t`（`kind=11`）视图名**（视图规则/禁止常量/响应/仲裁见 **§2.1**；`spec/00` §6 X5 注**已出列**，R-183），经 L1D 发出；walk 与数据请求的**仲裁口径见 §2.1**（T-08-3/T-06-5 已闭）。
- **翻译结果**：`mmu_transl_rsp_t`（含 `pa`/`fault`/`rw`/`super`，`spec/01` §3.14）；`rw` 保留码发出即违例（access-fault 兜底）。
- **TLB 填入纪律**：填入须与 `satp`/`sfence.vma` 序一致；**翻译一致性口径**（`satp` 写与 `sfence.vma` 的失效面）归 `spec/10` 定稿（登记 T-08-4）。

### 2.1 PTW 内存接口（`ptw_mem_req_t` 视图／仲裁／错误映射；RD ADR-1~4，R-183）

- **载体形态（ADR-1）**：`ptw_mem_req_t` **不另立类型**——＝`mem_req_t` 在 `kind==2'b11`（PTW）时的**规范化视图名**（`spec/01` §3.13 的 `kind` 码点即此用；锚：【权】1725「implicit memory accesses (such as to implement address translation)」）。下游端口类型写 `mem_req_t`，按本视图规则使用。
- **视图规则（ADR-2）**：`kind`≡`11`；`pa[43:0]`＝PTE 物理地址（`PA_BITS=44`；恒 8B 对齐）；`priv[1:0]`＝当前特权；`size`＝8B 码；`req_id[2:0]`＝outstanding 号（与 `mshr_wake_t.idx` 同域）；`seq` 无 PTW 语义（发 0、消费端不得依赖）；**原始访问类型不经本型携带**（单源＝`mmu_transl_req_t.rw`，PTW 内部持有至响应）；**不设 `level`**（`PTW_ENGINES=1`＋三层串行 ⇒ 在途读 ≤1，单发即匹配键）——回退点：二期多 walker／预取 walk ⇒ 增 `level`／walk-id。
- **禁止常量（协议违例 ⇒ `spec/11` 断言）**：`amo_op=0`、`sign_ext=0`、`rd_paddr=0`、`rob_id=0`、`lq_id/sq_id=0`、`is_fetch=0`、`ifetch_offset=0`、`va=0`。
- **响应（ADR-4）**：新增类型 **`ptw_mem_rsp_t`＝{`valid` 1, `data` 64, `err` 1, `code` 4}＝70 bit**（本节为定义处；`spec/00` §6 M12 行与 X5 注登记）；PTW 单发无需匹配键。
- **仲裁（ADR-3；T-08-3＝T-06-5 闭）**：**固定优先 walk、不设保留槽**（单发界 ⇒ 竞争面每拍 ≤1，不构成饿死源）；**允许与数据请求按同 64B 行合并**（`spec/09` §2 同口径）、**禁止对 PTE 读转发供数、禁止投机提前**（非幂等）；反压即等待（组合门控、不冲刷、不升格全局停，引 `spec/05` §2.5）；无环依赖（PTW 只等 L1D；L1D 服务不依赖 TLB）⇒ 无死锁。回退点：改轮转（1 行口径）。
- **err 映射（ADR-4；T-08-5 闭）**：**PTW 判定、MMU 组装**——PTE 取回失败／总线错 ⇒ access-fault（10）；PTE 非法／权限不满 ⇒ page-fault（01）；walk 隐式访问的 PMP/PMA 违规 ⇒ access-fault 优先（§4 现文口径）；经 `mmu_transl_rsp_t.fault/code` 输出。**`tval`＝原始访问 VA**（锚：【权】7453–7454「When a page-fault, guest-page-fault, or access-fault exception is taken, the relevant *tval CSR is written with the faulting effective address」；与 §4 判定次序、`spec/10` §4.2 口径一致）。
- **登记（ADR 汇总）**：**T-08-7**＝PTE 的 A/D 写回（RMW）载体——**本片不闭合**（预测＝L1D 写口复用或视图加 `we`＋`wdata[63:0]`（+65 b，须 `spec/01` §3.13 版本行）；归属本篇深化片，落文须取参考核锚）。

## 3. PMP / PMA

| 面 | 口径 | 引 |
|---|---|---|
| PMP | **PMP 8 项**（`spec/00` §2）；读/写/执行权限按项匹配；判定先于/后于翻译的次序以【权】§3.7 为准 | `spec/00` §2；【权】§3.7 |
| PMA | 静态区域表：`non-cacheable`/`strong-order`/`no-prefetch` 三类标记；**MAG PMA 不配置**（不实现 `Zama16b`，ADR-S06-A） | `spec/00` §2/§4.7/§8 |

| 取指面 | PMP 的 X 权限对取指生效；I 侧 fault 经 `ifetch` 通路 | `spec/01` §3.3/§3.14 |

## 4. fault 分流与 A/D 位

- **分流**（本篇口径）：权限/属性类 ⇒ **access-fault**（含 PMA 违规、保留码）；翻译缺失/权限位不满足 ⇒ **page-fault**；具体优先级次序待深化片与【权】§3.7 对账（登记 T-08-5）。
- **A/D 位**：**硬件置**（`spec/00` §5 D8）——PTE 的 A/D 由硬件在翻译命中时写入（PTW 已有 RMW 通路）；由此避免首 store 变 trap。
- **非对齐**：与 MMU 无关——非对齐一律 address-misaligned（`spec/00` §2；`spec/02` §18.2）。
- **异常提交抑制写**：翻译/权限 fault 属异常提交面 ⇒ 内存写不发生（`spec/02` §19 对照表行 3/5）。

## 5. 一致性/序纪律（单核面）

- **单核假设**：无多核一致性需求；L2 **non-inclusive**（`spec/00` §5 D10）；`LR/SC` 不在总线层实现独占（`spec/00` §8）。
- **fence / fence.i**：`fence` 处排空 SQ；`fence.i` 排空前端（IBUF/FTQ）并无效化 L1I 行（`spec/00` §8；`spec/02` §10.8）。
- **`sfence.vma`**：语义面（虚拟地址/ASID 失效粒度）归 `spec/10`；本篇锁：**执行后须使后续翻译不复用失效前 TLB 结果**（纪律句，拍序由 `spec/05` 引用）。
- **PMP/PMA 变更**：属 CSR 写面 ⇒ 随 `fence`/串行化口径（归 `spec/10`）。
