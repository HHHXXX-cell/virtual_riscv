### 2.2 C 族格式与展开级

- C 族格式（实读佐证）：CI（行 12427、12580、12834）、CR（行 12378）、CB（行 12418、12623）、CIW（行 12540）、CJ（行 12344）、CA（行 12755）；其余（CSS/CL/CS 等）待补。
- **展开级**：C→32 bit 展开在 M04 `vr1_cexpand` 完成（`spec/00` §4.3 `C_EXPAND_STAGES=1`、§6 M04）；展开后为 32 bit 流进 IBUF 出口。
- **长度判定的唯一位置**：16/32 bit 判定只在 P5 walk（`spec/01` §3.16：槽半字低 2 bit ≠`11`→16 bit，下一起始＝当前+1；=`11`→32 bit，下一起始＝当前+2；起始可落任意槽号；槽 15 起始 32 bit 走 `xw_carry` 拼接，ADR-1）。**M04 不重判长度**，只消费 `fetch_raw_t.is_c`（`spec/01` §3.3）。
- `is_c` 生命周期（五级）：`fetch_raw_t.is_c`（§3.3）→ `uop_t.is_c`（§3.4）→ `rob.type[0]`（§3.6/§3.7）→ `excp_t.is_c`（§3.18）→ `rt_t.is_c`（§3.21）。

## 4. 首批逐指令条目（3 类，每类给格式样板）

### 4.1 类①：x0（硬连线零）相关

**前提**：x0 硬连线为全零（AN-01，行 1964）；`spec/00` §4.3 窗口可达性口径：融合式 PRF 之 31 项常驻架构态（x1~x31）⇒ 投机在途含目的 μop ≤ `64−31 = 33`。

| 条目（样板） | misa 扩展位 | μop 分解（数＋类型） | 目的/源操作数规则 | 异常条件 | 与 ISS 的对应点 |
|---|---|---|---|---|---|
| JAL/JALR 且 rd=x0（伪指令 `j`/`jr`） | I | 1 个；分支类（`type.bit1`） | rd=x0 ⇒ `dst_kind=00`：不分配 PRF 目的、不消耗 free-list、不进映射栈（`spec/01` §5.3 仅 `dst_kind≠00` 弹栈，A14）；源＝pc+imm 或 rs1+imm | 目标非规范地址 → instruction access fault（`spec/01` §3.12 `bad_va`；异常码表归 `spec/10`） | trace 无 rd 写；`rt_t.is_br=1` |
| 载入 rd=x0 | I | 1 个；访存类（`type.bit5`） | 结果丢弃（AN-01）；**访存照常发起**；"rd=x0 是否豁免异常/副作用"本片未取证，不预设（T-8） | 地址非对齐（`MISALIGNED_EN=0` 报 fault）、page/access fault | trace 记该 load 退休、无 rd 写 |
| ALU/移位/乘法 rd=x0 | I/M | 1 个；`dst_kind=00` | 同上；源依赖照常建立（分发读口照常参与） | 无（除零不异常） | 无 rd 写 |
| CSRRS/CSRRC 且 rs1=x0 | Zicsr | 1 个；`type.bit6`，`dst_kind=11` | **不写 CSR**（AN-07）：无写副作用、不因只读 CSR 报 illegal；rd≠x0 时读旧值写 rd | 读侧照常（AN-07：恒读） | `csr_old` 有值、`csr_new = old`（§3.21 合成） |
| CSRRW 且 rs1=x0 | Zicsr | 1 个；同上 | **写 0 到目标 CSR**（AN-08，与 CSRRS/CSRRC 相反）；rd=x0 时同时"不读"（AN-06） | 只读 CSR → illegal（AN-11） | `csr_new` 按 wdata=0 合成（可写位清 0、只读位不变） |

**不变式**
- **I2-1**：任何 `rd=x0` 的 μop ⇒ `dst_kind=00`；不分配 PRF 目的、不消耗 free-list、回滚不归还（`rd_is_new=0`）。依据：AN-01 ＋ `spec/01` §5.3/A14。
- **I2-2**：x0 作源的读值恒 0；31 项常驻架构态口径（x1~x31）与在途上界 33 引用 `spec/00` §4.3，本篇不赋值。
- **I2-3**：x0 目的不产生任何架构状态变化与 trace 写字段（`rt_t` 无 x0 写，§3.21）。

### 4.2 类②：RVC（Zca）展开

**前提**：长度判定唯一在 P5（§2.2/I2-x），M04 只展开不重判；展开后进 `uop_t` 的 `isop` 与 32 bit 形式相同（§3.6 C-2）。

| 条目（样板） | misa 扩展位 | μop 分解（数＋类型；展开形式） | 目的/源操作数规则（含保留点/HINT） | 异常条件 | 与 ISS 的对应点 |
|---|---|---|---|---|---|
| C.NOP | C | 1；展开 `addi x0,x0,0`（=NOP） | 不改任何用户可见状态（AN-21）；imm≠0 = HINT | 无 | `is_c=1`；pc 递增 2 |
| C.ADDI | C | 1；展开 `addi rd,rd,imm` | rd=x0 ⇒ C.NOP；rd=x0 且 imm≠0 = HINT；rd≠0 且 imm=0 = HINT（AN-17） | 无 | 同上 |
| C.LI | C | 1；展开 `addi rd,x0,imm` | rd=x0 = HINT（AN-16） | 无 | 同上 |
| C.LUI | C | 1；展开 `lui rd,imm` | 仅 rd≠x2 且 imm≠0 合法；imm=0 保留；rd=x2 且 imm≠0 ⇒ C.ADDI16SP；rd=x0 且 imm≠0 = HINT（AN-16、AN-23） | 保留编码点 → illegal（化归 T-9） | 同上 |
| C.ADDI16SP | C | 1；展开 `addi x2,x2,nzimm[9:4]` | 目的固定 x2；nzimm=0 保留（AN-17） | 保留点 → illegal（T-9） | 同上 |
| C.ADDI4SPN | C | 1；展开 `addi rd′,x2,nzuimm[9:2]` | 立即数零扩展、非零、按 4 缩放；nzuimm=0 保留（AN-18） | 保留点 → illegal（T-9） | 同上 |
| C.ADDIW（RV64 专有） | C | 1；展开 `addiw rd,rd,imm` | 仅 rd≠x0 有效；rd=x0 保留（AN-17、AN-23） | 保留点 → illegal（T-9） | 同上 |
| C.J | C | 1；展开 `jal x0,offset`（±2 KiB） | 无链接写（rd=x0，走 §4.1 规则） | 无 | `is_c=1`、`is_br=1`；pc 递增 2 |
| C.JAL（RV32 专有） | C | （RV64 不实现） | RV64 同位编码点 = C.ADDIW（AN-13、AN-23）；RV32 语义：link=pc+2 写 x1（AN-12） | — | 不出现（RV64） |
| C.JR / C.JALR | C | 1；展开 `jalr x0,0(rs1)` / `jalr x1,0(rs1)` | C.JR 仅 rs1≠x0（rs1=x0 保留）；C.JALR 的 rs1=x0 编码点 = C.EBREAK（AN-14、AN-22）；link=pc+2 | 保留点 → illegal（T-9） | `is_jalr_ret` 绑定待补（T-7） |
| 全零 16 bit（0x0000） | C | — | 规范永久保留为非法指令（AN-20；全 1 同理） | illegal（T-9） | trace 侧须有异常条目 |

**不变式**
- **I2-4**：16/32 bit 判定**唯一**在 P5 walk（`spec/01` §3.16）；M04 展开级不得重判（否则双判定点会产生"同一字节流两种切分"的假绿）。
- **I2-5**：C 展开为 **1:1**（一个 C 指令产出一个 μop）——`UOP_MAX_SPLIT=2` 仅 DIV 与 AMO（`spec/00` §4.3）；C 类不拆包。
- **I2-6**：`is_c` 五级链（§2.2）逐级传递，任何一级丢失都会使 trace/ISS 的 pc 递增与异常现场口径分叉。
- **I2-7**：C.JALR 的 link 值（pc+2，AN-15）与 base 指令 JALR（pc+4）不同——RTL 与 ISS 两侧必须同口径，落实方式见 T-10（本片不定实现）。

### 4.3 类③：CSR（Zicsr）

**前提**：6 条 CSR 指令（AN-03）；读写条件三要素（rd、rs1、指令）见规范 Table 21（AN-10）；uimm 为 5 bit 无符号、零扩展（AN-09）。

|---|---|---|---|---|---|

### 9.2 计数与未决结构面（编码面的前置裁定项）

计数分解：`19＋9＋10＋11＋11＋13＋6＋8 = 87`（对应 C-4 的 1024−87＝937 余量）。列序说明：`ADDI` 等 19 项含 OP-IMM 9；OP-32 共 9（非 10）；RV64I 基础（不含 CSR/特权）为 53 项，含 CSR 6 与特权 4 及 SYSTEM 全组为 63 项（§10 计数按 63）。

未决结构面（下列七项未裁定前，任何下游不得按臆测实现——同 §3.6 撤销点口径）：
- (1) 立即数型与寄存器型是否共码（区分为 `imm_kind`＋`src_sel`（§3.8））——影响 §9.1.1／9.1.2／9.1.4。
- (2) 条件分支 6 条聚合为 1 码（条件内嵌 `isop` 域）或分列——两案对 `disp_x_t`（§3.11）无位宽影响。
- (3) 载入/存储是否按 `dm`（§3.8／§3.11）＋`sext` 聚合。 
- (4) CSR 6 条聚合形态（由 `csr_wr_type`（§3.11）与 `op`（§3.19）区分）——前置＝T-2。
- (5) NOP（C.NOP 展开目标）是否独立成员，及其与 `is_c`（§3.3）标记的配合。
- (6) `cls[2:0]`（§3.8）与本表成员的映射关系（登记缺口见 §12 的 T-19）。
- (7) `FENCE` 的 fm/pred/succ 承载域（复用 `imm` 44 bit 之一部或编码常量）——与 `spec/01` §3.8/§3.11 的 `imm` 语义边界相关。
