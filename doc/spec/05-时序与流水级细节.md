## 2. 关键拍序细则（各条只引不另定义）

### 2.1 发射选择拍（P9/W）与同组前递

- **值读点**：唯一读值拍＝`W`（发射选择）拍（`spec/01` §1.1/§3.5/§3.11；片①-A9 定案；`doc/spec/04` §4.1）。
- **组内前递（ADR-S12，2026-09-24）**：`R`（P7）级完成、**严格先于** `W` 读出拍；链长 ≤ `SAME_GROUP_BYPASS_DEPTH`（`spec/00` §4.3）；值侧经写口回灌，无同拍旁路（`spec/01` §1.1 `P7` 行／§4 注）。
- **等待口径**：`W` 拍到未就绪源 ⇒ 该 μop **不选中/留队重判**——不计重放、不入 `fwd_blocked_replay`（`spec/00` §9 口径不变）。
- **CSR 类门控**：入选需队头（`spec/01` §3.10 I-01/A16）；`src_val` 写口在 `W`（后读拍）落槽（§3.19）。

### 2.2 提交拍与释放拍序

- **提交点**：ROB 头、按序、4/拍（`spec/00` §4.5）；提交依赖链＝ROB 头 `finish`＋L1D 完成＋CSR 读（`spec/01` §4 BP2 不死锁论证）。
- **弹栈**：每提交一条写过 RAT 的 μop 从栈底弹一条；**exc 条目分支**同按 `rob_id` 配对（配对同法、不写新映射）＋撤销其投机映射（`spec/01` §5.2 `CT` 行①）。
- **槽释放**：`CT`③ **释放时刻＝冲刷生效拍**（`flush_apply` 当拍点火；checkpoint/rollback 两路径统一）（`spec/01` §5.2 `CT` 行③）。
- **回滚起弹拍**：`needs_ckpt=0` 路径**起弹拍＝`flush_apply` 生效次拍**；当拍仅压栈与门控（D3-②，`spec/01` §5.3）。
- **`K`＝迟到写窗口**：`K=2`（`spec/04` §3 定值；`spec/01` §7 A17 窗口 `1..K`）。

### 2.3 冲刷生效与二次冲刷

- **当拍仲裁**：checkpoint 路径 `SP := SP_ck` 覆盖胜出、冲杀压栈对当拍 `SP` 撤效；rollback 路径当拍压栈有效（D3-②）。
- **二次冲刷**：`rollback_busy=1` 期间再冲刷 ⇒ 目标更新＝严格更老；同级（`B_o==B`）无害吸收（D5-①，`spec/01` §5.3）。
- **重定向三路**：分支类＝`target_real`／串行化类＝提交时冲刷＋`ret_ctrl_t`／trap 类＝向量＋`mepc` 返回（`spec/01` §5.3 D3-①）。

### 2.4 唤醒/旁路拍序

- **广播**：`wb_t{valid,paddr,data}` ≤6/拍（`WAKE_BCAST_PORTS`，`spec/00` §4.4）；IQ 以 CAM 相联比较（`spec/01` §3.9）。
- **依赖间距**：ALU→ALU 3 拍；跨簇 +1（`BYPASS_CLUSTERS`）（`spec/00` §4.4）。
- **唤醒→选择**：同拍写回→次拍可选（构造性上界见 `spec/04` §3.3）。

### 2.5 反压拍序

- 六类反压点 BP1~BP6 的**级与出口条件**见 `spec/01` §4；本篇只锁**时序性质**：组合门控、不冲刷、不升格为全局停；`BP6` 触发时 FTQ 不得清空（`spec/01` §4 BP6）。
- 反压不改变「顺序点唯一」与「精确异常」两条根性质（`spec/00` §3）。

## 3. F2 `xw_carry` mux 时序专项（ADR-1 下游义务；`spec/00` §10 追踪行）

> 本节的**义务来源**：ADR-1（选 A：`xw_carry` 尾半字保持＋次窗拼接）在 `spec/00` §10 行明列「`spec/05` F2 定稿须纳入 `xw_carry` 装载/拼接路径的 mux 时序与选择信号（F2 mux 专项）」。
> **机制与位域不在此定义**：位宽与字段＝`spec/01` §3.16 ② 原文（62 bit＝1+16+40+1+4）；载荷/消费/作废/粘滞违例规则逐句引用 §3.16 ②④；块布局细则＝`spec/03` §2.4（B-1~B-4、I3-5、T-04）。本节只给**时序与选择信号**。

### 3.1 装载路径（本窗，槽 15 为 32 位起始）

| 项 | 时序表述（引） |
|---|---|
| 触发 | 本窗 F2 walk 于**槽 15** 判定「32 位起始（低 2 bit＝`11`）」——判定唯一在 P5（`spec/02` §2.2；M04 不重判） |
| 动作 | 当拍装载 `xw_carry`（首半字＋该指令起始 VA 等，字段见 `spec/01` §3.16 ②）；本窗 walk **止于槽 15**（`spec/03` T-04） |
| 选择信号 | **装载使能** = 「本拍 walk 处理槽 15」∧「判定为 32 位起始」；无其它写者（`spec/01` §3.16 ②） |

### 3.2 拼接路径（次窗，槽 0 消费）

| 项 | 时序表述（引） |
|---|---|
| 触发 | **次窗** F2 walk 处理到**槽 0** 且 `xw_carry.v=1` |
| 动作 | 当拍拼接＝「`xw_carry` 首半字」＋「槽 0 半字」→ 32 位指令候选；该条指令的**全部字节已到手**，本窗 walk 按其后续槽位继续（`spec/03` §2.4 B-2） |
| 选择信号 | **拼接选择** = `xw_carry.v` ∧ 「本拍 walk 处理槽 0」；mux 输出＝32 位候选（位域拼法＝`spec/01` §3.16 ② 原文） |
| 消费后 | 清 `v`（单次消费；`spec/01` §3.16 ②） |

### 3.3 交错与冲突边界

- **同拍既装又拼不成立**：装载触发于槽 15、拼接触发于槽 0，二者同拍互斥（同一 walk 拍只处理一个槽序位置）。
- **冲刷**：`xw_carry` **随冲刷作废**（不跨冲刷存活）——`spec/01` §3.16 ③／`spec/03` F4；冲刷优先于满/空与停工（`spec/03` F4）。
- **协议违例**：`v=1` 时再装载（前一拼接未被消费）⇒ 置**粘滞位**，禁止静默覆盖（`spec/01` §7 **A20（候选）**：`!xw_carry_overrun_sticky`；编号待 `spec/11` 定稿）。
- **幂等/时序稳定**：装载与拼接均为**单拍组合**动作（无握手、无跨拍缓冲）；`xw_carry` 的读—改—清三态在同一拍内完成（无中间态对外可见）。

### 3.4 专项出口

- **F2 mux 专项结论**：装载/拼接路径的**触发条件、选择信号、消费与作废时序**如上表——**机制无新增、位域无新增**（全部引用 `spec/01` §3.16 与 `spec/03` §2.4）。
- **下游义务**：`doc/verify/02` 的 `xw_carry` 验证点组（ADR-1 原列 ×6）在其建成时立项并回标（`spec/00` §10 追踪行）；`spec/11` 成稿落 A20 SVA 时汇总定稿编号。
