# doc/自动推进说明 — 角色与自动循环一页摘要

> 定位：**人读入口**。依据 `doc/项目开发流程.md` §12（人的介入点）、`AGENTS.md` §5.2 规则 23、`doc/AI角色与职责.md` §2/§3.1；
> 本页只是**索引式摘要**，与原文冲突时以原文为准。维护：R8（2026-09-24 建，R0 指令）。

## 0. 开工协议（会话第一件事；规则 24）

1. 读 `AGENTS.md`（本表与红线）→ 本页；
2. `python script/gate.py check`——**以实跑末行为权威**（0 FAIL 才可宣称"已落实"）；
3. 读 `doc/verify/03` **§0（工作项，行位＝顺序）／§1（切片，2~4h）** 与 `.qoder/handoff/HANDOFF.md` **最后一条**；
4. **取 §1 下一个 `待派` 切片直接开工**（审计/决策＝独立子代理；计划/开发/验证＝本体），按"派发→验收→归档→核销"五步，完成后**自动取下一切片**；
5. 待决项：设计/规格类 → 派 `vr1-decider`（ADR 四要素）；判定口径/放宽/无复核/环境权限类 → `escalate` 呈 R0；
6. **停机条件**：硬停机四类／§1 无待派且 §0 无待办／队列空／R0 叫停。**其余不请示**（`doc/项目开发流程.md` §12.2）。
7. **不得中途停（2026-09-24 R0 强化）**：未撞第 6 条之一 ⇒ **必须连续执行循环五步（一片接一片）**；**不得停轮、不得以"汇报进展/询问是否继续"结束本轮**；**明句：「按规则 24 循环五步执行，直到撞 §停机条件 之一，否则不得停下来报告。」**停下时须在 `HANDOFF.md` 明写"因撞【哪条停机条件】而停"。本条同时写入定时任务的开工 prompt。
8. **落文即派审（2026-09-25 加）**：**每批落文（≥1 片）后自动派 `vr1-auditor` 只读 δ 复核片**——复核面＝本批改动集∩本批声明落点（[元] 记录文本不入）；报告入评审记录**附 X**＋ISS 登记；**有阻塞⇒不得置「已核销」**，处置后再派窄复核；**禁止把复核攒到收口片**。与规则 24 ② 同源，三层（规则/协议/切片表）一致。
9. **处置必复（增量收敛，2026-09-25 加）**：**每轮处置后自动重派 `vr1-auditor` 增量复核片**（核修点按落点原文＋扫新增）；**新增 >0 ⇒ 继续「处置→复核」直到新增 0**；未达不得判收敛/呈签；收敛只见证、只能上报 R0（与 `doc/项目开发流程.md` §9.4 同源）。

## 1. 角色一览

**角色 R0~R8＋RD**（治理层：`doc/AI角色与职责.md` §2；**RD＝决策 AI，2026-09-24 新增**）；**红线 R1~R10** 是 `AGENTS.md` §5.2 的另一套记号——引用一律写全称「角色R6／红线R6」。

| 角色 | 职能一句话 | 写边界（要点） |
|---|---|---|
| **R0 人** | 唯一决策权：Review 签署、基线宣布、红线扩权 | `AGENTS.md` 状态栏／`doc/verify/10`／各"评审结论"节 |
| **R1 架构师** | 微架构规格、参数冻结、取舍留 ADR | `doc/spec/` |
| **R2 参考模型** | golden ISS、汇编器、trace 归一化 | `iss/`（禁读 RTL 反推） |
| **R3 设计** | RTL 实现与单元自检 | `rtl/`（G1 后只读） |
| **R4 平台与用例** | UVM、SVA、覆盖率模型、回归表 | `tb/` `filelist/` `run_cmd/` `script/` |
| **R5 归因调试** | 失败复现、根因、缺陷归因 | `doc/verify/06`、`debug/` |
| **R6 审计与收敛** | 一致性清单、台账闭环、waiver 审查 | `doc/verify/09`（只挑错） |
| **R7 对抗评审** | 单篇打靶，只出质疑清单 | 无写权限；**不下"通过"结论** |
| **R8 编排（PM）** | 派发、跟踪、逐轮机判核销 | 队列／看板状态列／`doc/verify/05` 调度段；**不接管任何角色的 A** |
| **RD 决策 AI（独立）** | 设计/规格类取舍**自决**（≥2 方案择优＋ADR 四要素）；**必报面第 0 次转人**；同一问题 **3 次未决熔断**出 ≤5 选项决策包 | ADR 一处登记＝`doc/process/00` 决策列＋相关篇 ADR 节；决策附录随评审记录；**独立派发**（不并入本体） |

**执行层子代理**（`.qoder/agents/`）：**五家均独立派发（2026-09-25 R0 恢复，撑销 ISS-079“并入本体”口径）**＝`vr1-planner`（计划：维护/重排 §0/§1 与派发序）｜`vr1-designer`（设计：spec/RTL 落文）｜`vr1-verifier`（验证：iss/tb/回归＋失败取证）｜`vr1-auditor`（评审，**角色R6＋R7 合并**；只读、不下"通过"结论）｜`vr1-decider`（**RD 决策 AI**，ADR 四要素＋必报面＋3 次熔断）。**主会话（R8）只做“按计划派发＋机判核销”**，不接管任何角色的 A。

## 2. 自动循环（每一轮）

1. **计划**：`doc/verify/03` §0 驱动计划（工作项，**行位＝唯一权威顺序**）＋§1 切片计划（2~4h 工单；状态只许 `待派/进行中/已核销`；"已核销"须带 R 行/台账 token）。
2. **执行**：R8 `python script/gate.py dispatch` 取队首 → 按 `role` 派发（**短派发词**：`run_cmd/派发词模板.md`，差异 ≤40 行＋预算）。**计划/开发/验证/评审/决策五类一律派对应子代理（2026-09-25 R0：不再本体直做）**。
3. **验收**：`gate.py check` **以实跑末行为权威**（有 FAIL 不得宣布"已落实"）；只读复核按「freeze → INIT → 派只读 → **收工即查**」取干净窗口；δ 面＝「本批改动集 ∩ 声明落点」。
4. **归档**：评审记录**附 X**／`doc/verify/05` R 行／`doc/process/00` ISS 行／`doc/verify/04` 看板镜像／`HANDOFF.md` 五字段条。
5. **决策**（遇设计/规格类待决项时插入）：派 `vr1-decider` 出 **ADR**（四要素）或按必报面 `escalate` 出 ≤5 选项决策包呈 R0。
6. **再计划**：批次收敛后由 **`vr1-planner`** 重排 §0/§1（R0 2026-09-25 恢复独立派发）；R8 只转录为队列项并归档。

**硬停机**（一律停下、出 ≤5 选项决策包）：`doc/项目开发流程.md` §12.1 的 P1~P4／§12.3 三类必报／评审 5 轮上限／红线 R9-R10 资源上限。

## 3. 人的介入点（`doc/项目开发流程.md` §12.1，只有四点）

① 三个 Review 签署；② 基线宣布；③ 红线扩权批准；④ §12.3 三类必报项拍板。**其余不请示**（AI 自决＋全部留痕，§12.2）。

## 4. 谁自决、谁停（速查）

- **R1~R5（含设计/验证面）**：写边界内自主执行；设计/规格类取舍自决并留 ADR（§12.2）——**2026-09-25 起恢复逐角色独立子代理派发**（撑销 09-24“并入本体”口径；留痕见 `doc/process/00` 与 `doc/verify/05`）。
- **R6/R7（vr1-auditor）**：只读；不得下"通过"结论；发现即登记台账（红线 R4）。
- **R8**：只驱动＋核销，**不得裁定**（不宣布评审关闭/阶段推进——红线 RA1）；四类硬停机转人。
- **RD（决策 AI）**：设计/规格类取舍自决（ADR 四要素＋外部锚点）；**必报面（放宽/waiver/无复核手段✅/环境权限）第 0 次转人**；同一问题 3 次未决熔断出决策包。
- **R0（人）**：唯一决策权；未拍板前 AI 不得默认通过（RA3）。

## 7. 角色作业守则（SOP；2026-09-24 R0 指令固化）

> 每方块＝"开工读什么 → 怎么干 → 产出/落点 → 停在哪里"。与 `AGENTS.md` 规则 19/23/24 配套；红线优先级最高。

### 7.1 本体＝**仅派发＋核销**（计划/开发/验证自 2026-09-25 恢复独立派发）
- **派发口径（2026-09-25 R0）**：计划/开发/验证三面改派 `vr1-planner`／`vr1-designer`／`vr1-verifier` 子代理执行；本体的职责链＝读 §1 → 派发 → 验收 → 归档 → 核销，产物由子代理产出、本体只转录与核销。
- **开工读**：`AGENTS.md` → 本页 §0 → `doc/verify/03` §0/§1 与 HANDOFF 末条 → `gate.py check` 末行。
- **怎么干**：取 §1 `待派` 切片 → 按 §1 行的"目标/写面/验收判据/预算"干活（细步骤执行中就定，不预写）；跨篇只登记；数值只引 `spec/00` §4。
- **产出/落点**：对应产物（spec/tb/iss/脚本）＋`doc/verify/05` R 行＋HANDOFF 五字段条＋必要台账/看板同步。
- **停在哪里**：撞硬停机四类／发现判定口径类待决（转 RD 或 escalate）／超预算（出部分结果＋说明）。
- **留痕纪律**：字节级补丁＋唯一命中断言；行尾不变量（`verify/05`=LF、其余=CRLF）；写后扫控制字符；禁止口头"已落实"。

### 7.2 审计（`vr1-auditor`，独立子代理；角色R6＋R7 合并）
- **开工读**：复核面三件（`machine_rNN_check/changed_all/width.txt`）＋本批 R 行/声明落点＋被审产物；**不读**作者当轮推理/对话。
- **怎么干**：只审「本批改动集 ∩ 声明落点」；逐条核销（已改/部分/未改）＋阻塞/澄清/存疑计数；复算抽查 ≥5（含转录基准行/标题位宽）；**只读、零写入**。
- **产出/落点**：报告以**文本返回**（R8 归档「附 X」）；不下"通过"结论；**不得**把窗口/结论留于忽略区。
- **停在哪里**：报告交回即止；发现阻塞不代修；**收工后由 R8 立即**跑 `rocheck --window`（收工即查）。
- **留痕纪律**：取证给"文件＋节号/锚点原文"；未做事项逐条声明（无执行工具则声明未重跑）。

### 7.3 决策（`vr1-decider`＝RD，独立子代理）
- **开工读**：待决项条目（台账/评审记录）＋相关 spec 节＋知识库卡 05。
- **怎么干**：判「自决面（设计/规格取舍）or 必报面（放宽/无复核✅/环境权限）」；自决＝≥2 方案择优＋**ADR 四要素**（选项评估／选定／外部锚点／下游义务）；同一问题 **3 次未决即熔断**出 ≤5 选项决策包。
- **产出/落点**：ADR 文本（R8 代录：台账决策列＋`doc/verify/05` R 行；**不改 spec**——落文归本体）。
- **停在哪里**：必报面**第 0 次即转人**；无锚点 ⇒ 降级"登记＋预测＋回退点"，不得记"已定"。
- **留痕纪律**：算式/估价手工留痕入 ADR；回退点必写；剩余分歧列条。

### 7.4 R8（领队；本会话＝与本体合一）
- **开工读**：同 7.1 第 1 条。
- **怎么干**：派发（短派发词 ≤40 行差异＋预算）｜验收（机判末行 0 FAIL）｜归档（附 X/R 行/ISS 行/看板/HANDOFF）｜核销切片（`已核销`＋token）｜**只驱动不裁定**（不宣布评审关闭/阶段推进）。
- **停在哪里**：硬停机四类 → `gate.py escalate` 出决策包呈 R0；R8 自身受 R6 审计。
- **留痕纪律**：队列/看板镜像/`doc/verify/05` 调度段为其写面；机判件（rNN 三件套）先于派发生成；长基线折入 ≤1 次/处置轮＋独立提交。

### 7.5 R0（人）
- **介入仅四点**：P1 G1 签署／P2 验证点评审／P3 基线宣布与重大变更／P4 G3 签核；＋§12.3 三类必报。
- **给出**：评审结论（按 AI 列出的 list 逐项签）／批准或否决／基线号；**其余不介入**（§12.2 AI 自决并留痕）。
