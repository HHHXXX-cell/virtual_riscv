# run_cmd/派发词模板.md — R8 派发词模板（短派发词口径）

> 依据：R0 2026-09-24 指令（本会话优化三条之二）——派发词过长导致子代理慢；本章把固定背景收进模板，
> R8 派发时**只写"差异部分"（≤40 行）**，其余引用本文件。模板自身变更同样记 `doc/verify/05`。
> 通用纪律：①派发词必须自足（子代理无主会话记忆）；②必读文件用**清单**给（子代理自行读，别在派发词里复述）；③带**预算**（目标时长／工具调用上限）；④回报格式要求"先结论清单、后证据"；⑤写面之外一切只登记。

## 0. 通用骨架（所有角色共用，逐段照填）

```
【角色】<vr1-designer|vr1-verifier|vr1-auditor|vr1-planner|vr1-decider>（写边界见 .qoder/agents/<角色>.md 与 AGENTS.md 规则 19）
【任务】<一句：做什么、挂哪个工作项/切片号>
【写面】<允许写的文件，逐件列出；其余只读>
【验收】<可核判据；不写死工具项数，以实跑输出末行为准>
【预算】<目标时长 h；工具调用上限 N；超限即停并回报部分结果>
【必读】(按序，只给文件/节，勿复述内容)
  1) AGENTS.md §…；2) <篇> §…；3) …
【硬约束】行尾不变量（<篇>=CRLF／verify/05=LF）＋字节级补丁＋唯一命中断言＋禁顺手重构
【回报】(1) 结论清单（≤10 行）(2) 证据（diff/实跑末行/锚点原文）(3) 偏差与未完成 (4) 核销申请：<R-行号或台账行>
```

## 1. 各角色差异位（只填这几格，其余引用 §0）

|---|---|---|---|---|

## 2. δ 复核轮的面（2026-09-24 R0 口径，替代原"全篇实读"）

- 只审：**本批改动集 ∩ 本批声明的落点**（`machine_rNN_changed_all.txt` 为下界）＋ 被改标识符的闭包项。
- **[元] 类（记录/台账/看板/交接等文本自产）不入 δ 面**——统一在批次末或 G1 前一次性扫。
- 全量档（§9.4b）不变：整篇＋缺失型遍历，仅节拍点使用。
- 派发时给复核面三件（`machine_rNN_check/changed_all/width.txt`）＋本批 R 行号即可，不再逐条列查项。

## 3. 批次与核销

- 小片合并：同一篇/同一面的 2~3 个微片并成一批派发，减少复核轮次（R8 派发时说明合并理由）。
- 核销：计划 §1 切片行状态只许 `待派/进行中/已核销`；`已核销` 必须带 R-行号或台账行 token（机判可查）。
